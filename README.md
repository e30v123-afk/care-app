# تطبيق أولوية العناية

قشرة أصلية حول متجر **careksa.com** (سلة) — لتحديث التطبيق `com.fc.firstcare`.

## ما يضيفه فوق المتجر
- شريط تنقّل سفلي عائم (الرئيسية · الأقسام · السلة · المفضلة · حسابي) مع شارة عدد السلة وارتجاج لمسي.
- ورقة أقسام منزلقة: المكياج، الوجه، العين، الحواجب، منتجات الترند، التخفيضات.
- رأس المتجر ثابت أعلى الشاشة، والمنطقة الآمنة تُبلَّغ من الطبقة الأصلية.
- الشريط يختفي تلقائياً عند فتح نوافذ سلة (الدخول، السلة، القائمة) فلا يغطي الحقول.
- شاشة انقطاع اتصال بهوية المتجر مع إعادة اتصال تلقائية، وسحب للتحديث.
- مشاركة المنتج عبر ورقة النظام، وتذكير محلي بالسلة المتروكة.
- فتح الروابط الخارجية في متصفّح النظام.

## ملاحظات على سلة
- `/profile` يعيد الزائر إلى الرئيسية، و`/login` لا يوجد — فتبويب «حسابي» يضغط زر
  الحساب في رأس المتجر (`i.sicon-user`) الذي يفتح `salla-modal.s-login-modal`.
- الصور بتحميل مؤجّل (`data-src` وsrc فارغ)، فبديل الصور المكسورة يتجاهلها
  حتى لا يستبدل صوراً سليمة.
- نوافذ سلة مكوّنات ويب بلا صنف `open`، فيُكشف ظهورها بالقياس وبإقفال تمرير الصفحة.
